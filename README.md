# E-Commerce Sales Data Analysis

## Project Overview

This project focuses on analyzing an e-commerce sales dataset to understand customer purchasing behavior, sales performance, and business trends. The dataset was cleaned and processed using Python, followed by exploratory data analysis (EDA) to identify patterns, trends, distributions, and outliers. The cleaned dataset was then prepared for visualization in Power BI.

## Objectives

* Clean and preprocess raw sales data.
* Calculate descriptive statistics such as mean, median, and count.
* Analyze sales trends and customer behavior.
* Identify outliers and unusual patterns.
* Generate insights to support business decision-making.
* Create an interactive Power BI dashboard using the cleaned dataset.

## Data Cleaning

The following preprocessing steps were performed:

* Handled missing values in the CouponCode column.
* Removed duplicate records.
* Verified and converted date columns to datetime format.
* Removed extra spaces from text columns.
* Created additional features such as Year, Month, and Day.
* Exported the cleaned dataset for Power BI visualization.

## Exploratory Data Analysis

### Descriptive Statistics

* Calculated mean, median, minimum, maximum, and count.
* Analyzed quantity, unit price, and total sales values.

### Distribution Analysis

* Quantity distribution
* Total price distribution
* Payment method distribution
* Order status distribution

### Trend Analysis

* Monthly revenue trend
* Product sales trend
* Customer purchasing patterns

### Outlier Detection

* Identified outliers using boxplots.
* Applied IQR method to detect unusual order values and quantities.

## Key Insights
